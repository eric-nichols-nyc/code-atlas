Implement `majorityElement(nums)` to find the number that occupies more than half of an integer array's positions.

An array of length `n` has a majority when one value occurs strictly more than `Math.floor(n / 2)` times. Every input has exactly one such value. Return that value as a number; its index and frequency are not the answer.

Values can be negative or zero, and the majority can appear anywhere in the array. A one-element array returns its only value. Exactly half the positions does not form a majority, so empty arrays and arrays without a strict majority are invalid custom cases.

The test panel accepts `nums` as a JSON integer array. This workspace uses 1–1000 values from `-1e9` to `1e9` to keep editable cases within the runner's input limits.

**Follow-up:** Can you traverse the array once using only a constant amount of extra space? Correct frequency-map and sorting solutions are also accepted.
