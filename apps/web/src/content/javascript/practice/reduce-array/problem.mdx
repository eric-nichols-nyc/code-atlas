Implement `reduceArray(nums, fn, init)` to combine an array into one numeric result.

Begin with an accumulator equal to `init`. Moving from left to right, call `fn(accumulator, nums[i])` once for each original element. Replace the accumulator with the returned value before processing the next element, then return the final accumulator.

Do not alter `nums`. With an empty array, return `init` directly without invoking the callback.

Choose a supplied reducer and edit both the JSON `nums` array and `init` in the test panel. `Array.prototype.reduce` and `Array.prototype.reduceRight` are disabled for this exercise.
