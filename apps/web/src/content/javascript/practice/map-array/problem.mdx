Implement `mapArray(arr, fn)` to create one transformed value for every input element.

Visit the original indices from left to right. At index `i`, call `fn(arr[i], i)` exactly once and put its returned value at the same position in a new output array. A returned zero must stay in the output; mapping does not filter values.

Leave the input array unchanged. An empty input returns a new empty array and makes no callback calls.

The test panel lets you edit `arr` and select a numeric transform. Its source appears below the selector. `Array.prototype.map` is disabled so your implementation performs the traversal itself.
