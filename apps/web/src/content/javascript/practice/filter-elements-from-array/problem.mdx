Implement `filter(arr, fn)` without calling the built-in `Array.prototype.filter`. Return an array containing the original elements that qualify for inclusion.

Call the supplied function with each element and its original index: `fn(arr[i], i)`. Keep an element when that return value is truthy. A callback can return a number or another non-boolean value; do not require its result to equal `true`.

Preserve the original values and their order. The callback decides which values to keep; its return value is not a replacement value.

In the test panel, edit the JSON array and select a supplied callback. Its source is shown beneath the selector. The built-in array filter method is disabled in this exercise so the implementation visits the elements itself.
