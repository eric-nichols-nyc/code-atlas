Write `createCounter(n)`. It should return a function that remembers a running count between invocations.

Calling the returned function for the first time gives `n`. Each later invocation gives the next integer. For example, a counter starting at 10 produces 10, then 11, then 12.

Keep each counter's state independent. Creating or calling a second counter must not reset or advance the first one.

In the test panel, `calls` is the number of times the judge invokes the returned function. The output collects those returned numbers in order. With zero calls, the output is an empty array.
