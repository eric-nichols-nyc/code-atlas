Implement `chunkArray(arr, size)` to divide an array into consecutive groups.

Take up to `size` values for each group, moving through the input in its original order. Every group except possibly the last must contain exactly `size` elements. Keep duplicates, zero and negative numbers; do not add padding or empty trailing groups.

Return a new outer array with a distinct new array for each group, even when two groups contain the same values. Leave `arr` unchanged. Empty input returns `[]`. When `size` exceeds the input length, return one group containing all input values.

The test panel accepts a JSON integer array and a positive group size. Standard methods such as `slice` are available; an external chunking library is not.
