## Two positions, one pass

A pointer here is an array index, not a memory address. With two indices, you can
compare values at different positions and decide which position to move next.
The useful part is the rule for moving them: each move should rule out work you
no longer need to do.

For example, suppose a **sorted array** contains two numbers that add up to a
target. Start with `left` at the beginning and `right` at the end. If their sum is
too small, move `left` forward to try a larger value. If it is too large, move
`right` backward to try a smaller value.

## Two-pointer Strategies

Two-pointer algorithms usually take only `O(n)` time by eliminating the need for
nested for-loops. There are three main strategies for using two pointers.

**Inward traversal**

This approach has pointers starting at opposite ends of the data structure and
moving inward toward each other:

![Left and right pointers start at opposite ends of an array and move toward the center.](https://bytebytego.com/images/courses/coding-patterns/two-pointers/introduction-to-two-pointers/image-01-00-4-SFTU7WGJ.svg?dpl=dpl_HeCpaNHcf76vgftfiqM4vj83MiuR)

The pointers move toward the center, adjusting their positions based on
comparisons, until a certain condition is met, or they meet/cross each other. This
is ideal for problems where we need to compare elements from different ends of a
data structure.

Examples: [Valid Palindrome](https://leetcode.com/problems/valid-palindrome/),
[Two Sum II - Input Array Is Sorted](https://leetcode.com/problems/two-sum-ii-input-array-is-sorted/),
[Container With Most Water](https://leetcode.com/problems/container-with-most-water/).

**Unidirectional traversal**

In this approach, both pointers start at the same end of the data structure
(usually the beginning) and move in the same direction:

![Two pointers traverse an array in the same direction, serving different roles.](https://bytebytego.com/images/courses/coding-patterns/two-pointers/introduction-to-two-pointers/image-01-00-5-2KI3FUD6.svg?dpl=dpl_HeCpaNHcf76vgftfiqM4vj83MiuR)

These pointers generally serve two different but supplementary purposes. A common
application of this is when we want one pointer to find information (usually the
right pointer) and another to keep track of information (usually the left pointer).

Examples: [Remove Duplicates from Sorted Array](https://leetcode.com/problems/remove-duplicates-from-sorted-array/),
[Remove Element](https://leetcode.com/problems/remove-element/),
[Move Zeroes](https://leetcode.com/problems/move-zeroes/).

**Staged traversal**

In this approach, we traverse with one pointer, and when it lands on an element
that meets a certain condition, we traverse with the second pointer:

Examples: [Next Permutation](https://leetcode.com/problems/next-permutation/),
[String Compression](https://leetcode.com/problems/string-compression/),
[Reverse Words in a String](https://leetcode.com/problems/reverse-words-in-a-string/).

The indices begin at `0` and `4`: `1 + 11` is too large, so `right` moves to `3`.
Now `1 + 7` is too small, so `left` moves to `1`. The values `2` and `7` add up
to `9`, and the function returns `[1, 3]`.

Each move makes the gap smaller. The search takes at most a linear number of
steps and uses constant extra space, apart from its returned pair. The sorted
input is what makes this movement rule valid; it does not work for an arbitrary
unsorted array.
