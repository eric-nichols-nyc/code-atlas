Implement `frequencySort(nums)`. Return the values in ascending order of frequency. When different values occur equally often, put the larger number first.

Keep every occurrence. With `[2,2,-1,4,-1,0]`, the result is `[4,0,2,2,-1,-1]`. `4` and `0` appear once each and come first. `2` and `-1` each appear twice, so `2` comes first between them.
