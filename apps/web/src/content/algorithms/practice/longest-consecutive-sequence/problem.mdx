Write `longestConsecutiveSequence(nums)` to return the length of the longest run of consecutive integers that appears in `nums`.

The integers in a run can occur at any indices. For example, `[7, 2, 4, 2, 3]` contains the run from 2 through 4, so the answer is `3`. Repeated values count once. Return `0` for an empty array.

Aim for O(n) time on average. Enter `nums` as a JSON array of up to 100,000 signed 32-bit integers.
