Implement `groupAnagrams(strs)`. Put two strings in the same group when they contain the same number of each letter. The arrangement of the letters can differ.

Return an array of groups and keep every occurrence from the input. Both the order of the groups and the order of the words within each group can vary.

With `["arc","care","car","race","dog"]`, one valid result is `[["arc","car"],["care","race"],["dog"]]`. Empty strings can form a group too.
