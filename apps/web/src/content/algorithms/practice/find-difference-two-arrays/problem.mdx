Implement `findDifference(nums1, nums2)`. Return `[onlyInFirst, onlyInSecond]`, where `onlyInFirst` lists the numbers found in `nums1` but absent from `nums2`, and `onlyInSecond` lists the numbers found in `nums2` but absent from `nums1`.

Include each number at most once per list. A number that appears in both inputs belongs in neither list. You can return the numbers within each list in any order.

With `[4,-2,7,4]` and `[7,3,-2]`, the result is `[[4],[3]]`. The second `4` in the first array still contributes just one `4` to the result.
