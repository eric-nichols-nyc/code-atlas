Write `findMaxConsecutiveOnes(nums)` to return the length of the longest uninterrupted run of ones. Each zero breaks the current run.

In `[1,1,0,1,1,1]`, there are two runs of lengths two and three, so the answer is `3`. An array containing only zeroes returns `0`.

Aim for one pass using O(1) extra space. Enter `nums` as a JSON array of 1–100,000 numbers, where every entry is either `0` or `1`.
