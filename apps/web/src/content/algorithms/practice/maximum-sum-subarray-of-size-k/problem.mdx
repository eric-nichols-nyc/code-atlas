Write `maxSumSubarray(arr, k)` to return the largest sum you can get from exactly `k` consecutive elements of `arr`.

For `[2, 7, 3, 5, 1]` with `k = 3`, the largest sum is `15` from `[7, 3, 5]`. The maximum can be negative if every window has a negative sum.

Enter `arr` as a JSON array of 1–100,000 integers from −10,000 through 10,000. Enter `k` as an integer from 1 through the length of `arr`.
