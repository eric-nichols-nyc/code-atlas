Write `countPairs(arr, target)` to count the pairs of indices `i` and `j` where `i < j` and `arr[i] + arr[j] === target`.

Count each matching pair of indices even when some of the values are equal. In `[2, 2, 2]` with a target of `4`, there are three matching pairs.

Enter `arr` as a JSON array of 1–10,000 integers. The array values and `target` must be integers from −10,000 through 10,000.
