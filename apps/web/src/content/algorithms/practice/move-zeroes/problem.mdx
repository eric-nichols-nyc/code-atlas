Write `moveZeroes(nums)` to rearrange the array so that all zeroes appear after the nonzero numbers. Preserve the order in which the nonzero numbers originally appeared.

For example, `[0,1,0,3,12]` becomes `[1,3,12,0,0]`. Negative numbers and duplicates follow the same ordering rule.

Change the original array in place. You can return that array or leave the function without a return value. The runner displays the contents of the original array after your function runs.

Aim for O(n) time and O(1) extra space. Enter `nums` as a JSON array of 1–10,000 signed 32-bit integers.
